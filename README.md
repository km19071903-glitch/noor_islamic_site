# نور — رفيق المسلم اليومي
## الملفات

- `public/index.html`: هيكل الواجهة.
- `public/styles.css`: التصميم المتجاوب والسمات الفاتحة/الداكنة.
- `public/app.js`: التفاعلات في الواجهة.
- `server.js`: خادم Express وواجهات الحساب والمفضلة.
- `package.json`: اعتماديات المشروع وأوامر التشغيل.

## واجهات API المتاحة

- `GET /api/health`
- `GET /api/me`
- `POST /api/auth/register` مع `email` و`password`
- `POST /api/auth/login` مع `email` و`password`
- `POST /api/auth/logout`
- `GET /api/favorites` (يتطلب تسجيل الدخول)
- `POST /api/favorites` (يتطلب تسجيل الدخول؛ الحقول: `type`, `itemId`, `title`, `text`, `source`)
- `DELETE /api/favorites/:id` (يتطلب تسجيل الدخول)

## ملاحظات قبل النشر

1. هذه نسخة أولية؛ نصوص القرآن والأحاديث والأذكار داخل الواجهة محدودة لأغراض العرض، وليست مكتبة كاملة. يجب استيراد النصوص من مصدر موثوق والتحقق منها ومراجعتها قبل إطلاق الموقع.
2. نموذج الحساب الظاهر في الواجهة حاليًا تجريبي، ولا يرسل الطلبات إلى API بعد؛ توصيل الواجهة بمسارات التسجيل وتسجيل الدخول هو خطوة تالية.
3. غيّر `SESSION_SECRET` إلى قيمة طويلة وعشوائية في بيئة النشر، واستخدم HTTPS.
4. مخزن جلسات Express الافتراضي مناسب للتجربة المحلية فقط. استخدم مخزن جلسات دائمًا ومناسبًا للإنتاج قبل النشر العام، وأضف حماية من محاولات الدخول المتكررة وقيودًا أمنية إضافية.
5. قاعدة البيانات تحتوي على حسابات ومفضلة؛ احمِ ملف `noor.sqlite` ولا ترفعه إلى مستودع عام.
